Why are the r, g, and b variables floats instead of ints, bools, or strings?
The values can only exist from 0 to 1, so to create a gradual shift in the colors, we use decimals. Also its not text, nor is it a true or false value.
Why is the _bounce variable an int instead of a float, bool, or string?
The ball cannot .5 bounce or .3 bounce so we keep it a whole number using int.
